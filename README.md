# 🎓 Student Management System (Spring Boot + JWT + MySQL)

A secure and efficient **Student Management System** built with **Spring Boot 3.5.6** and **Java 25**, featuring **JWT Authentication**, **MySQL database**, and complete **CRUD operations** for student data management.

---

## 🚀 Features

✅ Secure login and token-based authentication using **JWT**  
✅ Full **CRUD** operations for student records  
✅ Centralized **exception handling**  
✅ **Input validation** using Jakarta Validation  
✅ **Spring Data JPA** integration with MySQL  
✅ Configurable roles and access control  
✅ Lightweight and modular project structure  
✅ Ready-to-deploy Spring Boot backend

---

| Category | Technology |
